# 外部仕様

共用 Discord チャットボット「dis-llm-bot」の外部から見える振る舞いを定義する。
運用単位は 1プロセス = 1ペルソナ = 1ギルド = 1データベースである。

## 参加範囲

- 単一サーバ（`DISCORD_GUILD_ID`）にのみ参加し、他のギルドのイベントは無視する。
- 指定カテゴリ（`DISCORD_CATEGORY_IDS`、複数可）配下のテキストチャンネルでのみ発言する。
- 上記チャンネルのスレッド内発言にも応答する（親チャンネルのカテゴリで判定する）。
- 権限（閲覧・送信・履歴参照）のないチャンネルには読み書きしない。
- `READONLY_CHANNEL_IDS` 指定のチャンネルは読み取り専用であり、Botは投稿も返信もしない。
- DMおよび他Botの発言には反応しない。

## 応答条件

- BotへのメンションまたはBot発言へのリプライに必ず応答する。
- `RESPOND_ALL=true` の場合、対象チャンネルの全発言に応答する。
- 上記以外は応答しない（ランダム発言の対象にはなる）。

## 機能

- チャット応答：直近の会話履歴と長期記憶を参照し、OpenAI互換endpointに接続して回答を生成する。
- Web検索：Brave APIを用い、最新情報を要する質問に回答する。
- リンク・画像調査：投稿URLの本文抽出、添付画像のVision入力により内容を把握する。
- シェル実行：使い捨てコンテナ（networkなし、非root、cap-drop）で短時間コマンドを実行する。
- 記憶：会話内容を保存し、重要事項は長期記憶として蓄積する。記憶保存時は緑色のembedで通知する。
- ランダム発言：5分周期の判定により、対象チャンネルで時折自発的に発言する。
- 作業中表示：応答に3秒以上かかる場合のみ「考え中……」等のembedを表示し、tool実行に応じて文面を更新する。完了時に削除する。
- リアクション：応答したメッセージに対し、内容に応じた絵文字を1件まで付与することがある（確率＋チャンネル毎クールダウンで頻度を抑制）。
- ログイン通知：起動時に1回のみ緑色のembedを投稿する。
- エラー通知：応答生成の失敗時は赤色のembedで通知し、通常発言とは区別する。

## ペルソナ

- デフォルトペルソナを内蔵する。管理者は `PERSONA_PATH` で独自ファイルに差し替え可能である。
- 1プロセスは1ペルソナ固定であり、起動後の切替はできない。

## 複数Bot運用

- 同一Postgresサーバ内でペルソナごとにデータベースを分ける。各Botは自身のDBにのみ接続する。
- Botごとにトークン・ペルソナ・DB名を変えてプロセスを分ける。
