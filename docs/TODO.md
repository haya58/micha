

## 追加で実装したいこと
- 検索で時間がかかっているときにユーザに一次応答を返す → OK
- ユーザについて記憶をした際に「〇〇さんについて新しいことを覚えました！」と embed 応答を返す → OK（記憶保存成功時に緑embedで通知）
- メンションをつけなくても反応するモード切替機能を追加 → OK（`RESPOND_ALL=true` で対象チャンネルの全発言に応答。実行時コマンド切替は未対応）
- Bot のログイン時に「Botがログインしました」とEmbedで投稿するようにしてほしい
- Bot がエラーになった場合、通常の応答と区別するために明確なエラーメッセージを Embed で投稿するようにしてほしい

## 不具合？
- Bot の発言時に dls-llm-bot と先頭に出ることがある → OK（履歴形式「名前: 本文」の模倣が原因。応答・ランダム発言の送信前に既知の名前接頭辞を除去）
